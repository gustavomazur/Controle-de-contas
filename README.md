#Para rodar o Back end
- Rode o Comando na pasta do backend (pode ser no terminal do IntelliJ ou no terminal do sistema)
- Vai compilar e subir a API em http://localhost:8080
- Comando : ./mvnw spring-boot:run

---------------------------------------------------------------------------------------
#Front end mesma coisa
- npm install   # só na primeira vez
- npm start /toda vez

- Abre o Angular em http://localhost:4200
- O frontend já tá configurado pra chamar a API no localhost:8080
